# HTML & CSS Review Project (`html-review`)

A comprehensive, multi-page web project designed for coursework and lab work. This repository serves as a structured review guide and practical reference for fundamental HTML elements and CSS styling techniques.

## 🚀 Overview

`html-review` is organized into modular pages that break down core web development concepts. Each page demonstrates clean semantic markup, media integration, data presentation, and metadata configuration, all styled cohesively via a shared external CSS stylesheet.

---

## 📂 Project Structure

```text
html-review/
├── index.html          # Homepage / Overview
├── styles.css          # Shared external stylesheet
├── text-formatting.html# Text elements, typography, and semantic tags
├── media.html          # Images, audio, video, and iframe integrations
├── tables.html         # Structured tabular data and attributes
└── metadata.html       # Head elements, meta tags, and SEO basics
└── form.html.          # Form elements of html
└── links.html          # Links in html
└── semantic.html       # Semantic elements
