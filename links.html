HTML Links & Media Tags Tutorial

This section covers hyperlinks for navigation as well as embedding media such as images, audio tracks, and video clips into your webpage.

1. Hyperlinks (`<a>`)

Basic Hyperlink

The <a> tag uses the href attribute to specify the URL address of the destination page.

Example: Visit Google Search Engine

Opening Links in a New Tab (`target="_blank"`)

Adding target="_blank" opens the linked page in a new window or browser tab.

Example: Open Wikipedia in a new tab

Email and Phone Links

Using mailto: or tel: inside the href attribute allows users to send emails or make phone calls directly.

Example: Send us an Email or call Phone Support

Page Anchor / Internal Link

You can jump to a specific section on the same page by referencing its id.

Example: Jump to Project Author Section
