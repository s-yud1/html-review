HTML Text Formatting Tags Tutorial

Text formatting tags are used to change the visual appearance or semantic meaning of text in HTML documents.

1. Bold and Important Text

The <b> tag draws attention without extra importance, while <strong> indicates important or urgent text.

Example: This text is bold using <b> and This text is strong using <strong>

2. Italic and Emphasized Text

The <i> tag displays italic text for alternate voice or technical terms, while <em> adds verbal stress emphasis.

Example: This text is italic using <i> and This text is emphasized using <em>

3. Highlighted and Small Text

The <mark> tag highlights text, and <small> reduces font size for copyright or fine print.

Example: This text is highlighted using <mark> and This is fine print using <small>

4. Deleted and Inserted Text

The <del> tag displays strikethrough text (deleted), and <ins> underlines text (inserted).

Example: Special deal price: $100 $50

5. Subscript and Superscript Text

The <sub> tag defines subscript text (below normal line), and <sup> defines superscript text (above normal line).

Example: Water formula is H2O and math equation 102 = 100.

6. Computer Code and Preformatted Text

The <code> tag displays inline code snippets in a monospace font.

Example: JavaScript command: console.log("Hello World!");
