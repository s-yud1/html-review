HTML Metadata Tags Tutorial

Metadata provides information about the HTML document itself. It is placed inside the <head> element and is not directly displayed on the page, but helps browsers, search engines, and web services understand your site.

1. Document Title (`<title>`)

The <title> tag sets the title shown on the browser tab and in search engine search results.

Code Example:

<title>HTML Tutorial - Metadata</title>

2. Character Encoding (`<meta charset="...">`)

Defines the character encoding for the document so the browser renders letters, numbers, and special symbols correctly. UTF-8 covers almost all languages and characters.

Code Example:

<meta charset="UTF-8">

3. Responsive Viewport Tag

Essential for responsive web design, this tag tells mobile browsers how to scale the page width to fit small screens correctly.

Code Example:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

4. Search Engine Optimization (SEO) Tags

Description and keyword meta tags give search engines (like Google) summaries of your webpage content.

Code Example:

<meta name="description" content="A beginner tutorial learning HTML metadata tags.">

<meta name="keywords" content="HTML, CSS, Metadata, Web Development, Head Tags">

<meta name="author" content="HTML Review Project Team">

5. Linking External Resources (`<link>`)

The <link> tag connects external stylesheets or site favicons (the small icon displayed in browser tabs).

Code Example:

<link rel="stylesheet" href="style.css">

<link rel="icon" type="image/x-icon" href="favicon.ico">

6. Social Media Cards (Open Graph Tags)

Open Graph tags (prefixed with og:) control how your link, title, and image look when shared on social media platforms like Facebook, Twitter, or Discord.

Code Example:

<meta property="og:title" content="HTML Review - Metadata Tutorial">

<meta property="og:description" content="Learn how HTML head elements and metadata work.">

<meta property="og:image" content="preview.jpg">
