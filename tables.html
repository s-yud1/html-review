HTML Tables Tutorial

HTML tables allow you to organize data into rows and columns, making structured information easy to read and compare.

1. Basic Table Tags

A basic table is created using <table>. Rows are defined with <tr> (table row), column headers with <th> (table header), and standard data cells with <td> (table data).

Example:

Name Role Age
Alice Developer 28
Bob Designer 32

2. Table Semantic Sections (`<thead>`, `<tbody>`, `<tfoot>`)

To keep complex tables well-structured, HTML provides three grouping elements:

  • <thead> — Contains the header row(s).
  • <tbody> — Contains the main table content.
  • <tfoot> — Contains footer/summary info (e.g., totals).

Example:

Item Price
HTML Book $20
CSS Book $25
Total $45

3. Merging Cells (`colspan` & `rowspan`)

You can make a table cell span multiple columns or rows using attributes:

  • colspan="n" — Spans across n columns horizontally.
  • rowspan="n" — Spans across n rows vertically.
